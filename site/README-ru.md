# Сайт Hush & Hold

Две страницы из коробки: продающая страница гайда (главная) и страница донатов. Оплата через виджеты lava.top, переключатель USD / EUR (по умолчанию USD) в шапке и прямо над виджетом.

## Установка и обновление (на сервере, от root)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/rnovchinnikov-max/hush-hold-media/claude/project-thread-knhep3/site/install.sh)
```

Скрипт в конце печатает адрес студии и пароль. Повторный запуск той же команды обновляет код, а страницы, стиль и картинки остаются.

Если на сервере уже стоит бот автоответов, сайт встаёт на главный адрес (https://hushhold.uk/), а бот сохраняет свои адреса: /admin, /webhook, /auth, /privacy, /data-deletion. Копия старого конфига nginx лежит в /root/hush-autoreply.nginx.bak.

Другой домен: `DOMAIN=example.com bash <(curl ...)`.

## Студия (админка): https://ДОМЕН/studio

- **Страницы**: создать новую, выбрать главную, задать приоритет (порядок в меню), скрыть из меню, черновик или опубликована.
- **Блоки страницы**: первый экран, карточки, фото + текст, оплата/донат, вопросы, цитата, текст, Instagram, HTML. Блоки можно двигать, копировать и удалять.
- **Оплата / донат**: цены USD и EUR, по виджету lava.top на каждую валюту (вставляй iframe целиком), размер виджета.
- **Стиль**: 3 готовых стиля в один клик (ночной, Instagram, журнал) и ручная настройка цветов, шрифтов, скруглений, звёздного фона.
- **Картинки**: загрузка и удаление.
- **Настройки**: название, ссылка на Instagram, валюта по умолчанию, текст в подвале.

## Полезное

- Логи: `journalctl -u hush-site -n 50`
- Перезапуск: `systemctl restart hush-site`
- Пароль студии: `/opt/hush-site/config.env`, строка SITE_ADMIN_PASSWORD
- Данные: `/var/lib/hush-site` (site.db и uploads). Бэкап: `cp -r /var/lib/hush-site ~/hush-site-backup-$(date +%F)`
